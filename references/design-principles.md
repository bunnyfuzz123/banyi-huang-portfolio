

## Viewport / Beat Structure

Different beats do not need to exist as vertically stacked webpage sections.

A beat can be treated as a state that owns the viewport.

- Beat transitions can toggle visibility/display.
- Layers should overlap only when the overlap is intentional.
- Scroll/wheel can function as interaction input rather than literal page scrolling.
